YING DRINK WEBSITE — HƯỚNG DẪN
================================

Cấu trúc:
- index.html       Trang chủ
- menu.html        Thực đơn (lọc danh mục, tìm kiếm, chọn món)
- about.html       Giới thiệu thương hiệu
- contact.html     Liên hệ / biểu mẫu đặt món
- css/style.css    Giao diện responsive, CSS Grid/Flexbox/Box Model
- js/main.js       Menu điện thoại, lọc/tìm món, xử lý form demo

Cách chạy trên máy:
1. Giải nén thư mục.
2. Mở index.html bằng Chrome/Edge.
3. Để trải nghiệm tốt hơn, mở thư mục bằng VS Code và chạy bằng Live Server.
4. Hình ảnh và Google Fonts dùng đường dẫn online nên cần internet.

Triển khai miễn phí bằng GitHub Pages:
1. Đăng nhập GitHub và tạo repository mới, ví dụ: ying-drink.
2. Upload toàn bộ file/thư mục trong gói này lên repository (index.html phải ở thư mục gốc).
3. Mở Settings > Pages.
4. Trong Build and deployment, chọn Deploy from a branch.
5. Chọn branch main và folder /(root), nhấn Save.
6. Chờ GitHub tạo địa chỉ dạng https://TEN-TAI-KHOAN.github.io/ying-drink/
7. Mở đường dẫn đó để kiểm tra website.

Lưu ý:
- Đây là website frontend tĩnh. Form đặt món/đăng ký email chỉ hiển thị thông báo demo, chưa lưu dữ liệu,
  chưa gửi email và chưa có thanh toán trực tuyến. Muốn nhận đơn thật cần backend hoặc dịch vụ form.
- Không cần hosting PHP/MySQL cho bản hiện tại.
- Nếu dùng tên miền riêng, thêm domain tại Settings > Pages và cấu hình DNS theo hướng dẫn GitHub.
- 000webhost đã ngừng hoạt động; GitHub Pages là lựa chọn miễn phí phù hợp cho website HTML/CSS/JS tĩnh.
